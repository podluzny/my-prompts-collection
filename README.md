# My Prompts Collection

Коллекция промтов для работы: UX-экспертиза, продуктовый дизайн, анализ требований и AI-инструменты.

Каждый промт — отдельный файл, который можно скопировать целиком и использовать сразу. Промты проверены на реальных задачах; где это возможно, у них есть методика, источники и примеры результатов.

Автор — [Дмитрий Подлужный](https://www.podluzny.ru/), Head of UX, 17 лет в проектировании цифровых продуктов.

## Как пользоваться

1. Откройте нужный файл и скопируйте промт целиком.
2. Вставьте его в чат с моделью (или в инструкции проекта / Custom Instructions / системный промт).
3. Приложите материалы, которые запрашивает раздел «Входные данные» промта: скриншоты, текст, контекст задачи.
4. Если модель задаёт уточняющие вопросы или формулирует допущения — проверьте их: от контекста сильно зависит качество ответа.

Если промтом вы пользуетесь регулярно, его удобнее оформить как Skill (Claude) или Custom GPT (ChatGPT), чтобы не вставлять вручную каждый раз.
